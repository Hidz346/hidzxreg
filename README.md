# HidzXreg

HidzXreg is a lightweight gaming utility by HIDZ PROJECT.

## Included

- Sensitivity range calculator
- Effective DPI calculator
- Device performance profiles
- HUD starting-point presets
- Performance guidance
- Responsive mobile/desktop interface
- Vercel-ready static deployment

The site runs entirely in the browser and does not modify game files, inject code, bypass anti-cheat systems, or attempt to evade bans/blacklists.

## Deploy to Vercel

1. Import `Hidz346/hidzxreg` into Vercel.
2. Keep the framework preset as **Other** (static).
3. Leave Build Command empty.
4. Leave Output Directory as the project root.
5. Deploy.

No environment variables or database are required for this version.
